# NeurIPS 2026 Workshop Website

Static GitHub Pages website for the NeurIPS 2026 Workshop on Agentic AI Trustworthiness.

## Files

- `index.html` - page content and structure
- `styles.css` - responsive UI and visual system
- `script.js` - mobile navigation, active section highlighting, committee search
- `neurips/` - source proposal materials

## Preview

Open `index.html` directly in a browser. No build step or package installation is required.

## GitHub Pages

1. Push this repository to GitHub.
2. Open repository Settings.
3. Go to Pages.
4. Set source to `Deploy from a branch`.
5. Select the main branch and `/root`.
6. Save.

The site will be served from the repository's GitHub Pages URL.
